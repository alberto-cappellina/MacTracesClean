# MacTracesClean

Personal privacy utility for macOS (native SwiftUI). It analyzes, **read-only**,
what is exposed on your Mac and can optionally clean the traces away. No data
ever leaves the Mac.

## Features

**Privacy audit** (read-only, nothing leaves the Mac)
- Safari / Chromium (Chrome, Edge, Brave, Arc) / Firefox history
- Shell history, flagging commands that contain secrets
- Recently opened documents
- Recent downloads
- Plaintext credentials and keys (`~/.aws`, `~/.ssh`, `.env`, …) — values masked
- Known Wi-Fi networks
- Leftovers of uninstalled apps under `~/Library`
- Assorted privacy artifacts (Quick Look, Spotlight, Messages, Mail, Notes…)

**Trace cleanup** (dry-run by default, optional backup, files sent to Trash)
- Browser history · Shell history (secrets only or all) · Quick Look cache
- Downloads older than N days · Leftovers of uninstalled apps (high-confidence only)
- Credentials are **never** touched automatically.

## Build & run

```bash
cd MacTracesClean
./build.sh
```

The script generates the project with XcodeGen, builds it with `xcodebuild`, and
launches the app. The `.xcodeproj` is generated by XcodeGen (`xcodegen generate`)
and is not checked in: regenerate it with `./build.sh` or `xcodegen generate`,
then open it in Xcode and press Run.

## Full Disk Access

To read Safari, Mail, Messages and similar sources, add **MacTracesClean** under
System Settings › Privacy & Security › **Full Disk Access**, then relaunch the
app. Without this permission the related sections stay empty; the app flags this
and offers a button to open the settings.

## Technical notes
- Not sandboxed (required to read `~/Library`).
- SQLite databases are read from a temporary copy, so the app does not interfere
  with a running browser.
- No external dependencies: just SwiftUI + the system SQLite3.
- Real cleanup runs can first copy the affected files into
  `~/MacTracesClean_backups/<timestamp>/` when backup is enabled.
